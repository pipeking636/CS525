# B+树的节点公式：
B+树中节点可以包含的“键”的最大个数为n，n一般在B+初始化时被设置为一个固定值，例如100。
|                | Max ptrs | Max keys | Min ptrs          | Min keys          |
| -------------- | -------- | -------- | ----------------- | ----------------- |
| Non-leaf (non-root) | $( n + 1 )$  |  $n$  | $\frac{n+1}{2}$ | \( \lceil \frac{n+1}{2} \rceil - 1 \) |
| Leaf (non-root)     | $( n + 1 )$  |  $n$  | \( \lfloor \frac{n+1}{2} \rfloor + 1 \) | \( \lfloor \frac{n+1}{2} \rfloor \) |
| Root                | $( n + 1 )$  |  $n$  | \( 2^* \)         | \( 1 \)           |
* 根节点如果是叶节点，则可以有0个键和1个指针；如果是非叶节点，则至少有2个指针和1个键。

# B+树节点的分裂操作：
当一个节点中的键的个数大于最大键数n时，需要进行分裂操作。分裂操作会考虑两个部分：\
## 1. 分裂节点：将当前节点一分为二，遵循“半满”原则。将中间键插入到父节点中。具体情况分为四种\
    1.1 当n为奇数时：
        1.1.1 当n为奇数时，对于叶子节点：因为，n为奇数，所以当一个叶子节点中的键的个数为n时，（n+1）为偶数，可以被2整除，所以分裂后的左右节点中键的个数分别为(n+1)/2和(n+1)/2。\
        例如：n=3, 一个叶子节点当前有3个键[1,4,9], 此时插入一个新的键5，叶子节点会变成[1,4,5,9]。此时节点中的键的个数大于n，需要将该节点分裂。根据“半满”原则，分裂后的节点为[1,4]和[5,9]。\
        1.1.2 当n为奇数时， 对于非叶子节点：因为，n为奇数，所以当一个叶子节点中的键的个数为n时，（n+1）为偶数，可以被2整除，所以分裂后的左右节点中键的个数分别为(n+1)/2和(n+1)/2。但是，将原中间键删除并上推（Push）插入到父节点中。这种情况等价于将分裂后的右节点的第一个键删除并插入到它的父节点中。\
        例如：n=3, 一个非叶子节点当前有3个键[1,4,9], 此时插入一个新的键5，非叶子节点会变成[1,4,5,9]。此时节点中的键的个数大于n，需要将该节点分裂。根据“半满”原则，分裂后的节点为[1,4]和[5,9]。然后将原中间键5，也就是分裂后的右键的第一个key删除并插入到它的父节点。所以，最终结果是[1,4]和[9]。\
    1.2 当n为偶数时：
        1.2.1 当n为偶数时，对于叶子节点：因为，n为偶数，所以当一个叶子节点中的键的个数为n时，（n+1）为奇数，不能被2整除。所以，分裂后的左右节点中键的个数分别为((n+1)/2)+1和(n+1)/2。\
        例如：n=2, 一个叶子节点当前有2个键[1,4], 此时插入一个新的键5，叶子节点会变成[1,4,5]。此时节点中的键的个数大于n，需要将该节点分裂。根据“半满”原则，分裂后的节点为[1,4]和[5]。\
        1.2.2 当n为偶数时，对于非叶子节点：因为，n为偶数，所以当一个非叶子节点中的键的个数为n时，（n+1）为奇数，不能被2整除。所以，分裂后的左右节点中键的个数分别为((n+1)/2)+1和(n+1)/2。但是，将原中间键删除并上推（Push）插入到父节点中。这种情况下等价于把分裂后的左节点的最后键删除并插入到它的父节点中。\
        例如：n=2, 一个非叶子节点当前有2个键[1,4], 此时插入一个新的键5，非叶子节点会变成[1,4,5]。此时节点中的键的个数大于n，需要将该节点分裂。根据“半满”原则，分裂后的节点为[1,4]和[5]。然后将原中间键4，也就是分裂后的左节点的最后键删除并插入到它的父节点。所以，最终结果是[1]和[5]。\
## 2. 更新父节点：如果当前节点是根节点，需要创建一个新的根节点；如果当前节点不是根节点，需要更新父节和父节点的指针。操作方法和非叶子节点的方法相同。
## 3. 注意点：
    - C语言的正整数除法的结果会自动向下取整，因此上面的公式是正确的，不需要特殊处理。
    - 上面的例子中只体现了Key的情况，在插入和删除key的同时还需要调整相应的指针。例如，在插入一个新的键时，需要将新键插入到正确的位置，并且更新相应的指针。在删除一个键时，需要将删除的键从节点中移除，并且更新相应的指针。
    - 根据上面的说明，我们发现需要先考虑插入后的节点情况再进行分裂操作。因为B+树中Key值是有序排列，所以如果在插入前就先分裂，有可能导致新插入的Key值违法有序性。例如，在插入一个新的键时，需要有序排列，再判断插入后的节点是否超过最大键数n。如果超过，才需要在有序排列的基础上进行分裂操作。
# B+树的节点下溢（underflow）
当一个节点中的键的个数小于最小键数时，需要进行下溢操作。下溢操作会考虑两个部分：\
## 1. 合并节点：将当前节点和它的一个兄弟节点合并。合并后的节点中键的个数为n。\
## 2. 更新父节点：如果当前节点是根节点，需要删除根节点；如果当前节点不是根节点，需要更新父节点的指针。操作方法和非叶子节点的方法相同。\
## 3. 注意点：
    - 合并节点时，需要考虑当前节点和它的兄弟节点的顺序。如果当前节点是左兄弟，需要将右兄弟的第一个键插入到当前节点中；如果当前节点是右兄弟，需要将左兄弟的最后一个键插入到当前节点中。\
    - 合并节点时，需要考虑当前节点和它的兄弟节点的指针。如果当前节点是左兄弟，需要将右兄弟的第一个指针插入到当前节点的指针中；如果当前节点是右兄弟，需要将左兄弟的最后一个指针插入到当前节点的指针中。\
