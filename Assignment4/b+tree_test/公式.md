# B+树的节点公式：
B+树中节点可以包含的“键”的最大个数为n，n一般在B+初始化时被设置为一个固定值，例如100。
|                | Max ptrs | Max keys | Min ptrs          | Min keys          |
| -------------- | -------- | -------- | ----------------- | ----------------- |
| Non-leaf (non-root) | \( n + 1 \)  | \( n \)    | c) | \( \lceil \frac{n+1}{2} \rceil - 1 \) |
| Leaf (non-root)     | \( n + 1 \)  | \( n \)    | \( \lfloor \frac{n+1}{2} \rfloor + 1 \) | \( \lfloor \frac{n+1}{2} \rfloor \) |
| Root           | \( n + 1 \)  | \( n \)    | \( 2^* \)         | \( 1 \)           |

# B+树的分裂操作
当一个节点中的键的个数大于最大键数n时，需要进行分裂操作。分裂操作会考虑两个部分：
1. 分裂节点：将当前节点一分为二，遵循“半满”原则。将中间键分裂到父节点中。半满原则的公式是：需要被分裂出去的键的个数 = n - \(\lceil \frac{n+1}{2} \rceil - 1\)。当n=3时，需要被分裂出去的键的个数为3-(3+1)/2 +1 = 3-2+1=2。
例如：n=3, 一个叶子节点当前有3个键[1,4,9], 此时插入一个新的键5，叶子节点会变成[1,4,5,9]。此时节点中的键的个数大于n，需要将该节点分裂。根据“半满”原则，分裂后的节点为[1,4]和[5,9]。
2. 更新父节点：如果当前节点是根节点，需要创建一个新的根节点；如果当前节点不是根节点，需要更新父节点的指针。如上例子，一个叶子节点分裂后，需要将右节点的第一个键5，作为中间键，插入到父节点中。如果父节点在插入新的键后，键的个数大于n，也需要进行分裂操作。操作方法相同。
